# Prior-work check

Search date: 2026-11-14, America/Indianapolis. Roughly ten-minute search window (03:52–04:03 UTC on November 15), including reading candidate methods and resolving unavailable PDFs. This is a bounded search, not a systematic review or a novelty guarantee.

**Outcome:** prior research already synthesizes comedy and examines timing. I did not verify a study measuring automatically produced **pre-punchline** gaps against matched expected endings, or coupling those gaps to token surprisal. The distinction is based on the papers' methods, not merely their titles. The brief's stop rule concerns existing punchline-pause measurement in synthetic speech; the closest synthetic duration work below does not identify its measured intervals as punchline boundaries. Proceed only as exploratory work and avoid any “first study” claim. If more directly overlapping evidence appears, stop and reassess.
